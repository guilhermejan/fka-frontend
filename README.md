# 🛍️ FKA Imports · Frontend

Interface web do FKA Imports: catálogo e páginas administrativas conectadas ao backend do projeto.

> 🤖 Projeto construído com assistência de IA na geração e alteração do código. Guilherme é estudante de Engenharia de Software, atualmente focado em Java, e ainda está desenvolvendo autonomia de programação. As tecnologias descritas representam contato prático assistido, não domínio independente ou certificação.

## Tecnologias presentes

HTML, CSS e JavaScript, com fontes e ícones externos. O repositório inclui configuração para Netlify.

## Organização

| Caminho | Responsabilidade |
| --- | --- |
| `index.html` | Página principal |
| `acesso.html` e `fecca.html` | Páginas adicionais da interface |
| `css/` | Estilos do site, administração e insights |
| `js/api.js` | Integração com a API |
| `js/site.js` | Comportamentos do site |
| `js/admin.js` e `js/admin-insights.js` | Comportamentos administrativos |
| `assets/` | Recursos visuais |

## Estado e cuidados

Projeto sem uso atual pelo autor, mantido privado. Depende da API e das configurações do ambiente original; uma interface que abre não comprova que todas as integrações funcionam.

Antes de uma demonstração, revise endpoints, contatos, imagens e permissões de uso. Não use dados reais de clientes. A revisão documental não executou o sistema nem auditou seu histórico.

## Experiência registrada

Contato assistido com interfaces web, organização de arquivos, painel administrativo e comunicação entre frontend e backend.
